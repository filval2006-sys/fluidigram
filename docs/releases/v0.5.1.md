# Fluidigram 0.5.1

## English

A fix for the macOS installer, and the first update you can try from inside the app.

### Fixed
- **macOS: the installer now replaces the existing app instead of creating a second copy.** Version 0.5.0 installed into your personal *Applications* folder, so a copy already in `/Applications` was left behind. The installer now always uses `/Applications` (it asks for your password once), replaces the previous version, and removes the duplicate that 0.5.0 may have left in your personal *Applications* folder.
- **macOS: the app belongs to the person who installed it**, so **Settings → Updates → Update now** can replace it without asking for a password.

### Upgrading
- **If you have 0.5.0:** open **Settings → Updates** and press **Update now**. This is a good first test of in-app updates. Afterwards, if you also have an older copy in `/Applications`, drag it to the Trash (macOS asks for your password).
- **If you have an older version:** install this one by hand (instructions below); it replaces the copy in `/Applications`.
- Your `.fluidigram` projects are not touched.

## Italiano

Una correzione dell'installer per macOS e il primo aggiornamento che puoi provare dall'interno dell'app.

### Correzioni
- **macOS: l'installer ora sostituisce l'app esistente invece di creare una seconda copia.** La versione 0.5.0 installava nella tua cartella *Applicazioni* personale, quindi una copia già presente in `/Applications` restava lì. Ora l'installer usa sempre `/Applications` (chiede la password una sola volta), sostituisce la versione precedente e toglie il doppione che la 0.5.0 può aver lasciato nella tua cartella *Applicazioni* personale.
- **macOS: l'app è di chi l'ha installata**, così **Impostazioni → Aggiornamenti → Aggiorna ora** può sostituirla senza chiedere la password.

### Aggiornamento
- **Se hai la 0.5.0:** apri **Impostazioni → Aggiornamenti** e premi **Aggiorna ora**. È un buon primo test degli aggiornamenti dall'app. Poi, se hai anche una copia più vecchia in `/Applications`, trascinala nel Cestino (macOS chiede la password).
- **Se hai una versione più vecchia:** installa questa a mano (istruzioni qui sotto); sostituisce la copia in `/Applications`.
- I tuoi progetti `.fluidigram` non vengono toccati.
