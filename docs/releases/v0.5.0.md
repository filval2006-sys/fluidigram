# Fluidigram 0.5.0

## English

Fluidigram can now **update itself**. This is the last version you need to install by hand: from here on, new versions install from inside the app.

### New
- **Update now.** In **Settings → Updates** the app checks whether a newer version is available and, if so, downloads it, verifies its signature, installs it and restarts — no browser, no installer to run. Your projects are not touched.
- **Automatic check with a notification dot.** Once a day the app looks for a new version by itself; a red dot appears on the Settings button when one is out. You can turn the automatic check off in the same page.
- **Release notes in the app:** a *What's new* button opens the notes of the new version.

### Changed
- **The installers now install for your user only** (macOS: your *Applications* folder; Windows: per user, no administrator permission). This is what lets the app replace itself without asking for a password.
- The only network request the app makes is the update check (a plain web request to `github.com`). It is described in Settings and in the README, and can be turned off.

### Upgrading from an earlier version
- **Install this version once by hand** (see the instructions below). From then on updates are automatic.
- If you had installed an older version **for all users**, remove the old copy to avoid having two: on macOS drag `/Applications/Fluidigram.app` to the Trash; on Windows uninstall Fluidigram from *Settings → Apps*.
- Your `.fluidigram` projects open as before.

## Italiano

Fluidigram ora può **aggiornarsi da solo**. Questa è l'ultima versione da installare a mano: da qui in poi le nuove versioni si installano dall'interno dell'app.

### Novità
- **Aggiorna ora.** In **Impostazioni → Aggiornamenti** l'app controlla se c'è una versione più nuova e, se c'è, la scarica, ne verifica la firma, la installa e si riavvia — niente browser, niente installer da eseguire. I tuoi progetti non vengono toccati.
- **Controllo automatico con pallino di notifica.** Una volta al giorno l'app cerca da sola una nuova versione; se ce n'è una compare un pallino rosso sul pulsante Impostazioni. Nella stessa pagina puoi spegnere il controllo automatico.
- **Note di rilascio nell'app:** il pulsante *Novità* apre le note della nuova versione.

### Cambiamenti
- **Gli installer ora installano solo per il tuo utente** (macOS: la tua cartella *Applicazioni*; Windows: per utente, senza permesso di amministratore). È ciò che permette all'app di sostituirsi da sola senza chiedere la password.
- L'unica richiesta di rete dell'app è il controllo degli aggiornamenti (una normale richiesta web a `github.com`). È descritta nelle Impostazioni e nel README, e si può spegnere.

### Se arrivi da una versione precedente
- **Installa questa versione una volta a mano** (istruzioni qui sotto). Da lì in poi gli aggiornamenti sono automatici.
- Se avevi installato una versione precedente **per tutti gli utenti**, togli la vecchia copia per non averne due: su macOS trascina `/Applications/Fluidigram.app` nel Cestino; su Windows disinstalla Fluidigram da *Impostazioni → App*.
- I tuoi progetti `.fluidigram` si aprono come prima.
