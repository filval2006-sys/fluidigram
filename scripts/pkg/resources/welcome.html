Fluidigram

Fluid system (P&ID) diagrams for model rocketry.

This installer puts Fluidigram in the Applications folder of your user account, so the app can update itself later without asking for an administrator password. It works fully offline.

Schemi fluidici (P&ID) per il razzomodellismo. Questo installer mette Fluidigram nella cartella Applicazioni del tuo utente, così l'app potrà aggiornarsi da sola senza chiedere la password di amministratore. Funziona offline.
